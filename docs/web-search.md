# 随航伙伴 Web Search

## 配置与使用

在项目根目录 `.env` 填写 `TAVILY_API_KEY`，然后重启后端。密钥只在服务端读取；前端仅获知是否配置。无需新增依赖，HTTP 使用现有 httpx，工具封装使用已有 LangChain Core。

```dotenv
TAVILY_API_KEY=
COMPANION_WEB_TOKEN_BUDGET=100000
COMPANION_WEB_TIME_BUDGET=90
WEB_SEARCH_TIME_BUDGET=40
WEB_EVIDENCE_TOKEN_BUDGET=10000
WEB_CONTEXT_TOKEN_BUDGET=18000
WEB_SEARCH_CACHE_SECONDS=1800
```

在太空探索中打开随航伙伴，输入需要公共资料、最新事实、文件或官方文档的问题。输入区的“联网 · 自动”允许模型按需调用；关闭后该条消息不联网。未配置密钥时明确显示“联网未配置”，普通陪伴仍可使用。

这是通用工具，不限制问题主题，没有固定学校、学历、专业、年份、搜索词或搜索域名。模型使用当前问题及必要上下文消解指代，不得擅自改变用户背景。域名不确定时留空，不猜测官网。用户问题有歧义时可先澄清。

## 工作流与工具契约

LangGraph：`load → plan_web → [search_web] → respond → validate → publish → 原有操作确认流程`。

`plan_web` 使用 DeepSeek Flash 原生 `bind_tools`，只注册 `web_search`；模型不需要联网时不调用。需要时返回查询、目的、可选域名、是否需要原文、主题和时间范围。`search_web` 使用 `StructuredTool` 执行，内部由服务端限制搜索与读取，不能执行任意工具或网页指令。

工具先从当前消息和已知背景中提取主体、行动、受众、版本和时间条件，保存原话及出处。本轮明确给出的同类条件优先。每批搜索合并结果后，模型同时查看完整候选目录、已读节选和未核实条件，分别给出值得精读的链接、明确冲突的来源和可供回答引用的证据。标题直接覆盖多项条件的原文优先进入精读，发布时间与适用年度分别判断。来源编号始终按发现顺序分配，编号本身不表示优先级。

每次用户提问至多两轮、四条搜索请求，每条最多六个结果，精读最多四个 URL。每批最多精读两项，读完重新核对正文和覆盖情况。附件也参与筛选。已有直接目标优先读取；有补搜计划时为新候选预留精读名额。取得足够证据后提前停止。补搜后整批重排，新来源可成为首选。已派发的请求计入预算，恢复时跳过已尝试的 URL。正文由 Tavily Extract 提供。

普通聊天继续使用原 80,000 tokens / 60 秒配置。实际调用搜索的消息提升至至少 100,000 tokens / 90 秒；所有模型决策、缺口分析和回复累计计费，重试不清零。40 秒是联网请求的累计活跃预算，整轮另受 90 秒总预算约束；扩展查询前为最终答复预留资源。

## 证据与前端

每轮来源编号从 W01 开始，独立于路径案例编号。保存标题、URL、来源主机、搜索摘要、读取状态、原文、提取节选、服务估计的来源日期和实际检索时间。服务估计日期不等于原始发布日期或生效日期；是否适用仍需阅读原文确认。

核对原文的节选默认共用约 10,000 tokens，回答输入默认上限为 18,000 tokens，另受本轮剩余额度约束。这两个上限可分别通过 WEB_EVIDENCE_TOKEN_BUDGET 和 WEB_CONTEXT_TOKEN_BUDGET 调整。长文按问题选取连续段落，表格尽量保留列名及相关行。回答沿用通过适用性检查的节选，依次精简旧聊天、背景和节选以适配剩余预算。另附完整来源目录。若目标原文读取失败，可提供已发现的链接并说明缺口。界面列出各来源的读取状态和选择结果，Trace 记录每批精读的编号及回答实际收到的证据。

引用必须使用本轮实际提供的来源编号与连续原文。正文 `[W01]` 与引用记录一致；结论中的数值应能在引用或来源标题的明确文字中核对，例如文件年份可来自标题。校验按完整数字匹配，不能用“30”支持“3”。要求原文的问题不能把仅有摘要的数值作为已核实结论。网页内容不能作为用户完成任务或拥有能力的证据，状态写入仍要求本轮用户原话。

索要文件时支持独立的标题引用。其引文与结论均须等于完整来源标题，界面标明“仅引用文件标题”。若已经取得适用原文、但生成的条款引文连续两次未通过校验，仍可交付可点击的文件来源，并说明条款未核实。

界面展示实际查询、来源读取成功/失败、部分资料未核实的提醒、可展开的引文与原始链接。Trace 展示真实节点及搜索/精读/缓存/预算事件，不模拟逐字输出或公开模型思考。刷新后可继续回看来源与引用。

## 降级与边界

未配置、服务鉴权失败、限流、超时、空结果、附件不可读时，保留已有资料并如实标注。未搜到不能推断文件不存在；未读到不能假称已经核实。PDF 由提取服务尝试读取，未实现独立 OCR；扫描件、登录页和部分复杂页面可能失败。

工具只将最小必要查询发送给搜索服务，提示模型不发送整段聊天或敏感个人信息；额外过滤常见凭证、邮箱与手机号。此过滤不代表能自动识别所有敏感信息。工具只接受公共 HTTP(S) 来源，过滤本机/内网地址、凭证 URL 和常见签名参数；目标正文仍交由 Tavily 读取。公共资料缓存默认 30 分钟，保留原检索时间，最多 200 个条目，可将缓存秒数设为 0 禁用跨轮缓存。

当前为单用户、单进程本地原型。引用编号、连续引文和数值校验能拦截部分编造，但不构成对所有结论的语义证明，重要决定应核对原始文件。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
npm run build --prefix frontend
```

联网测试使用虚构数据和 mock HTTP，包括通用主题、工具路由、用户关闭、未配置、去重、PDF、部分失败、引用与数值校验、次数/时间预算、缓存、恢复、与任务进度隔离。未配置真实 Tavily 密钥时不进行真实供应商调用。

接口依据：[Search](https://docs.tavily.com/documentation/api-reference/endpoint/search.md)、[Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract.md)。
