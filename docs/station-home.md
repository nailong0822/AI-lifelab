# 空间站检索首页

首页使用 React Three Fiber / Three.js 渲染程序化观景舱：八边形厚窗框、金属舱壁、顶部横梁与灯带、透视地板，以及窗外行星和远处设施。模型、材质、行星着色与反射环境均由本地代码生成，不依赖外部模型地址或 CDN。

两侧舱壁采用低不透明度材质，可以透出舱外太空；地面为不透明实体材质并写入深度缓冲，遮住地板后方的地球。窗框、结构梁、地板网格与灯带保留实体质感，静态降级图采用同样的透明关系。相机位置与朝向固定，移除鼠标驱动的镜头视差，避免顶部横梁和整个舱体跟随鼠标晃动；地球自转与星星闪烁独立保留。

## 组件

- `frontend/src/components/StationEnvironment.tsx`：检测 WebGL2 与设备能力、加载三维模块、处理渲染错误和静态模式、监听页面可见性与减少动态偏好。
- `frontend/src/components/StationScene.tsx`：固定机位的舱体几何、缓慢自转的行星 Shader、1600 个分布在不同深度的闪烁星点、140 个舱内微尘点。卫星包含金属框架、带凹凸细节的金色隔热层、反光太阳能电池片、散热片、通信碟与天线；纹理均在本地生成。
- `frontend/src/components/station-environment.css`：玻璃透射与反光、角部金属连接件、46 个辅助微尘、奶龙投射台，以及深浅色适配。
- `frontend/public/station/observatory-fallback.svg`：无 WebGL、节省流量、低内存、渲染失败或用户选静态模式时的本地降级图。FastAPI 与 Vite 均可提供 `/station/` 素材。

## 交互

输入台聚焦时增强玻璃边缘和微尘亮度；鼠标移动改变局部玻璃反光位置。提交检索时增强粒子亮度，仍使用现有检索 API。奶龙图片与“和奶龙聊聊”按钮都打开原有陪伴会话。首页不再重复显示悬浮奶龙。

底部“动态场景 / 静态场景”控制只影响装饰背景。静态模式卸载 WebGL，保留界面操作。操作系统选择“减少动态效果”时停止地球自转、星星闪烁、粒子漂移和奶龙浮动；三维场景只按需要绘制。地球只绕自身轴转动，太阳照明方向保持固定；切到后台后也会暂停。

## 性能与边界

三维模块按需分包加载，设备像素比上限 1.4，动态刷新约 30 帧。页面隐藏或背景离开视野后停止定时刷新，组件卸载时清理定时器、监听器、几何和环境纹理。WebGL 上下文丢失或加载失败会回到静态背景，表单和聊天不依赖渲染成功。

奶龙仍为透明 PNG，通过漂浮、投射光束和地台光环展示；没有把静态图片伪装成可转身的三维角色。玻璃使用浏览器 backdrop-filter 与多层反光，属于屏幕空间模糊透射，并非物理光线追踪折射。

调整视觉时保留轻量级降级图和减少动态适配；不要为提高辉光强度而让场景覆盖输入文字。
