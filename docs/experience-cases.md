# 探索经历案例

太空探索页面的“经历复盘”和“整理我的经历”可结束当前探索。选择达成目标、阶段目标、调整方向、暂停或结束尝试，并填写实际反馈。后台将原问题、澄清、路径版本、有效任务进度和随航对话整理成私人草稿。关闭窗口后继续运行，刷新可恢复查看。

草稿可修改标题、摘要、13 个结构字段和回顾。自动提取的事实保留原消息或任务编号及连续原文，展开“核对整理依据”查看。计划、助手建议和任务预计工时不能证明实际行动及投入。忘记的消息与即时安全危机回复对应的对话轮次跳过。

勾选确认后点击“保存并匿名分享”，才会进入内部检索。公开副本只包含审阅后的案例字段、摘要、结果类型和分享时间。原问题、对话、私人引文及路径编号保存在私人记录中。分享前需检查姓名、机构组合等可识别信息，自动隐藏仅覆盖部分常见联系方式与凭证。

修改已分享案例会撤下其公开副本，需要再次授权。同一条航线重新整理并分享时替换此前的公开版本，不同航线可分别保留案例。“撤回分享”同步删除公开副本与全文索引。新检索及已保存的检索结果在读取时重新核对分享版本，过滤撤回或已更新的案例；此前已经显示的内容与生成过的聊天文字属于历史记录。

## 实现

- LangGraph 工作流执行分批事实提取和草稿整理，每批结果在 SQLite 中保存，失败重试复用已完成批次。
- SQLite 中的 experience_cases 存放私人输入快照、证据、任务进度、草稿和授权状态。
- experience_public 仅存当前授权的公开内容，experience_fts 使用 FTS5，预先构建中文二字词和英文词以支持中文召回。
- 检索 Agent 首批知乎查询时同时召回最多 6 个内部候选。两路候选共用事实校验、字段权重、匹配分及覆盖率逻辑。内部召回不占知乎请求次数。
- 内部案例来源为 lifelab，字段证据范围标为 user_confirmed。网页和路径页面可打开 /shared-cases/{id} 查看授权内容。
- 相同提交编号与相同输入快照防止重复创建，编辑采用 revision 检查，发布和更新索引使用事务。

默认独立预算为 80,000 tokens / 180 秒，可通过 EXPERIENCE_TOKEN_BUDGET 和 EXPERIENCE_TIME_BUDGET 调整。重试保留累计用量。

接口包括 POST /api/paths/{id}/experiences、GET /api/paths/{id}/experiences、GET/PUT /api/experiences/{id}、POST /share、DELETE /share、POST /retry，以及只返回公开副本的 GET /api/shared-cases/{id}。

私人草稿、原始对话及整理依据通过账号归属校验控制访问。管理员的专用接口提供最终生成的复盘文档和摘要。已授权的公开副本可通过匿名案例页面查看。后台任务根据所属路径确定用户，并使用该用户保存的 DeepSeek API Key。
